## 5. Phase 2 feature wish list (implemented below)

From final-score game logs we can compute rolling features without any
additional data pull:

| # | Feature | Category | Data source | Notes |
|---|---|---|---|---|
| 1 | `pt_diff_l5_home` | Rolling team rate | game logs | Rolling pt differential L5 home team |
| 2 | `pt_diff_l5_away` | Rolling team rate | game logs | Rolling pt differential L5 away team |
| 3 | `pt_diff_l5_diff` | Rolling team rate | derived | home − away |
| 4 | `win_pct_l10_home` | Rolling team rate | game logs | Win % L10 home team |
| 5 | `win_pct_l10_away` | Rolling team rate | game logs | Win % L10 away team |
| 6 | `win_pct_l10_diff` | Rolling team rate | derived | home − away |
| 7 | `b2b_home` | Schedule fatigue | game logs | Home played yesterday? (0/1) |
| 8 | `b2b_away` | Schedule fatigue | game logs | Away played yesterday? (0/1) |
| 9 | `b2b_diff` | Schedule fatigue | derived | b2b_away − b2b_home (positive = away disadvantaged) |
| 10 | `rest_days_diff` | Schedule fatigue | game logs | (home rest days) − (away rest days) |
| 11 | `srs_diff` | Strength prior | source_history.db | Pre-existing season-level SRS from bref connector |
| 12 | `home_court_flag` | Structural | constant | Always 1.0 — needed for logistic intercept interpretability |

Deferred to Phase 3 (require additional data pull):
- Per-game box-score ORtg/DRtg (need nba_api TeamGameLog per season — feasible but slow)
- Pace differential (same)
- Injury/lineup availability (Underdog API or rotowire)
- Referee home-whistle tendency (bref referee pages — bref still 403s)
